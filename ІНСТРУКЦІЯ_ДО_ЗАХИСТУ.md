## 3. GitHub Pages

1. Увійдіть на https://github.com/ і створіть публічний репозиторій **kolo-tech** (або інша назва).
2. Розпакуйте архів. Завантажте в корінь репозиторію **index.html, styles.css, app.js, README.md** та **папку assets/**. Обов'язково збережіть структуру директорій.
3. В репозиторії: `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`.
4. Реальна публічна адреса залежатиме від логіна й імені репозиторію. Для `kolo-tech`: `https://ВАШ-ЛОГІН.github.io/kolo-tech/`.
5. Переконайтеся, що сайт справді завантажується. **Вставте його фактичну адресу на слайд №12 PPTX.**

## 4. Сценарій живої демонстрації (2–3 хв)

1. Відкрийте головну: поясніть концепцію re-commerce і чесного продажу повернень.
2. Перейдіть до каталогу; знайдіть «кавомашину», скиньте пошук, встановіть стан B.
3. Відкрийте картку: покажіть тести, комплектацію, недоліки та умовну ціну.
4. Додайте товар до кошика, змініть кількість і перевірте підсумок.
5. Спробуйте вибрати пилосос категорії C — продемонструйте попередження про дефект.
6. Покажіть блок градацій A/B/C, FAQ та **авторство у підвалі**.
7. Продемонструйте мобільну версію (режим телефона у DevTools браузера).
