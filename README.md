# KOLO — навчальний інтернет-магазин поверненої техніки

Інтерактивний адаптивний демонстраційний сайт, створений за допомогою ШІ для лабораторної роботи №5. Чиста реалізація **HTML + CSS + JavaScript**, без сторонніх бібліотек, баз даних та платних сервісів.

## Що працює

- Адаптивна головна сторінка, навігація, мобільне меню.
- Каталог із 8 демонстраційними товарами та авторськими SVG-ілюстраціями.
- Пошук, фільтри категорій, станів, наявності й ціни; сортування.
- Картки товарів з тестами, недоліками, комплектацією й категорією A/B/C.
- Обрані товари та кошик із збереженням у `localStorage` браузера.
- Попередження для несправного товару категорії C.
- Підсумок демонстраційного кошика; реальної покупки, платежів чи відправки даних немає.
- FAQ, пояснення бізнес-моделі, авторський підвал, семантична розмітка.

## Як запустити локально

Відкрийте `index.html` у сучасному браузері. Також можна запустити локальний сервер у цій папці:

```bash
python -m http.server 8000
```

Потім відкрийте http://localhost:8000 .

## Розміщення на GitHub Pages

1. Створіть **публічний** репозиторій (наприклад, `kolo-tech`).
2. Завантажте до **кореня репозиторію** файли `index.html`, `styles.css`, `app.js`, `README.md` і папку `assets/` з усіма SVG-файлами.
3. `Settings → Pages → Build and deployment → Deploy from a branch`, виберіть `main` і `/(root)`, потім `Save`.
4. Після публікації адреса матиме формат `https://ВАШ-ЛОГІН.github.io/kolo-tech/` (точне посилання залежить від назви репозиторію).
5. Відкрийте це посилання та перевірте каталог, кошик і зображення. Вставте **отримане** посилання у презентацію на слайд 12.
