## Бізнес-ідея

KOLO — навчальний прототип інтернет-магазину для роздрібного продажу побутової техніки з клієнтських повернень. Концепція проєкту — надати покупцеві зрозумілу інформацію про стан кожного товару: результати перевірки, комплектацію, відомі недоліки та ціну.

## Тип сайту та технології

- **Тип:** інтернет-магазин (демонстраційний вебпрототип).
- **Технології:** HTML5, CSS3, JavaScript.
- **Хостинг:** GitHub Pages; статичний сайт без серверної частини.
- **Адаптивність:** компонування для комп’ютерів і мобільних пристроїв.

## Реалізовані функції

- Каталог товарів із пошуком, фільтрацією та сортуванням.
- Картки товарів із характеристиками, категоріями стану A/B/C, результатами перевірок і описом дефектів.
- Обрані товари й інтерактивний кошик із локальним збереженням даних у браузері.
- Інформаційні розділи про підхід до оцінювання товарів, процес купівлі та відповіді на запитання.
- Контактні відомості й зазначення авторства в підвалі сторінки.

## Обмеження демонстраційної версії

Товари, ціни, доступність, описи перевірок та зображення створено для навчальної демонстрації. Онлайн-оплата, обробка замовлень і реальна торгівля не здійснюються. Позначення станів A/B/C є власною демонстраційною системою KOLO.
